# Agent‑Native Documentation Template

Agent‑native docs are designed for agents to read, execute and explain.  They should still be understandable by humans when needed.

## Objective

Describe the goal or functionality of the system or component.

## Context

Explain the environment, dependencies, relevant files and existing notes.  Include diagrams or links if helpful.

## Concepts and Definitions

List any terms or concepts the agent must understand.

## Step‑by‑Step Instructions

Provide ordered instructions.  Use declarative statements rather than imperative commands.  For example: “Implement a REST API that exposes endpoints for creating and reading notes” instead of “Create `app.js` and write code …”.

## Examples

Give one or two examples of expected input and output.  Keep examples simple and focused.

## Common Pitfalls

List mistakes to avoid, edge cases and known bugs.

## Tests and Verification

Describe how the agent should verify its work (unit tests, integration tests, manual checks).

## Follow‑up Tasks

Suggest next steps or related improvements.
