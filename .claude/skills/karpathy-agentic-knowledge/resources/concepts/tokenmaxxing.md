# Tokenmaxxing

**Tokenmaxxing** refers to a trend where workers deliberately consume as many AI tokens as possible, treating token usage as a productivity metric. Karpathy confessed on the **No Priors** podcast that he feels nervous when he has unused token budget and will switch from Codex to Claude to maximise his usage. Tech leaders have begun offering generous token budgets and monitoring consumption.

## Drivers

- **Parallel agent workflows:** Tools like Claude Code, Codex and AutoResearch allow agents to run autonomously for hours, spinning up sub‑agents and consuming large volumes of tokens.
- **Leaderboards and incentives:** Some companies create internal leaderboards to rank employees by token usage and reward top consumers.
- **Status signalling:** In certain corners of Silicon Valley, using more tokens is seen as a proxy for being ahead of the AI curve.

## Criticisms

- **Vanity metric:** Critics argue that tokenmaxxing rewards activity over outcomes and can lead to waste and burnout.
- **Costly:** High token consumption incurs significant bills; leaders worry about budgets and sustainability.
- **Wrong optimisation:** The real metric should be **inference yield** – the value delivered per token – not raw consumption.

## Guidance for the Skill

- Emphasise **inference yield**: define metrics that measure value (e.g., tests passed, bugs fixed) per token consumed.
- Avoid equating productivity with token usage. Use tokens wisely to achieve verifiable goals.
- Encourage concurrency where appropriate but ensure each agent’s work has success criteria.
