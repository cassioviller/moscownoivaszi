# Random Notes from Claude Coding (January 2026)

These notes summarise key points from Andrej Karpathy’s January 2026 post “A few random notes from Claude coding quite a bit last few weeks,” which reflects on his experience using agents for programming.

## Workflow Shift

- Karpathy rapidly shifted from 80 % manual coding and 20 % agent coding in November 2025 to 80 % agent coding and 20 % manual edits by December 2025. This phase shift mirrors the broader inflection point in software engineering.
- Agents execute “large code actions” (entire files or features) rather than line‑by‑line edits.

## Mistakes and Overengineering

- Agents no longer make simple syntax errors but often **overcomplicate code**, build brittle abstractions, make wrong assumptions and fail to seek clarifications.
- They may remove or modify unrelated code and comments as side effects.
- Use the **CLAUDE.md** guidelines (simplicity first, surgical changes, goal‑driven execution) to mitigate these issues.

## Tenacity, Speedups and Leverage

- Agents exhibit relentless stamina, working for hours without fatigue.
- They enable coding tasks that would have been impractical due to time or skill constraints, expanding the scope of what one person can build.
- Provide success criteria and let agents loop until they meet them.

## Fun and Atrophy

- Programming with agents feels more creative and fun because drudgery is removed.
- Manual coding skills may **atrophy**; generation (writing code) and discrimination (reading code) are different cognitive skills. Continue practicing manual coding or use tools that maintain skill.

## Slopacolypse and Questions

- Karpathy braces for a 2026 **slopacolypse** of low‑quality AI output; see the `slopacolypse.md` note.
- He wonders how 10× engineers will fare, whether generalists will outperform specialists and what future coding will feel like.

## Actions for the skill

- Encourage the use of templates to define success criteria, manage complexity and maintain quality.
- Balance automation with manual practice to prevent skill atrophy.
- Track the evolution of agent behaviour and update guidelines accordingly.
