# Macro Action Template

Use this template to delegate a significant feature or change to an agent.

- **Objective:** What should the agent deliver?  Describe the feature, refactor or research outcome.
- **Scope:** What parts of the codebase or knowledge base can the agent change?
- **Out of scope:** What must remain untouched?
- **Context:** Provide relevant files, notes or background.
- **Success criteria:** Define how you will evaluate the output (tests, benchmarks, qualitative checks).
- **Tests:** List automated tests or verification steps the agent must run.
- **Permissions:** Specify which tools the agent can use (e.g., CLI, browser, API).
- **Restrictions:** List any operations or dependencies that are disallowed.
- **Post‑task:** After completion, the agent should create a note summarising what was done, decisions made, and next steps.
