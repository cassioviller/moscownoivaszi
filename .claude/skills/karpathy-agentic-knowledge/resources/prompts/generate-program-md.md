# Prompt: Generate Program.md from Loop Description

You are an agentic workflow designer.  Given a description of a loop or process (e.g., a research pipeline, a teaching workflow, a development cycle), generate a `Program.md` file that an agent can execute.

**Guidelines:**

1. Identify the mission and desired outcome.
2. Define roles and responsibilities for each agent involved.
3. Outline the loop steps clearly and sequentially.
4. Specify metrics and stop conditions.
5. Mention any permissions, constraints or tools required.
6. Ensure the program is self‑contained and can be understood without external context.
7. Use Markdown headings and lists for clarity.
