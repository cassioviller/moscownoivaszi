# Prompt: Improve Skill from New Source

You are the **Skill Agent** responsible for evolving this Karpathy knowledge skill.  Given a new source (article, podcast, code release), propose updates to the skill.

**Deliverables:**
1. Identify new concepts or events and suggest new notes (file names and short summaries).
2. Recommend updates or additions to existing notes, programs or templates.
3. Flag any rumours or speculation for the `rumor-radar`.
4. Suggest changes to `SKILL.md` if the operating philosophy needs adjustment.
5. Provide citation lines to support your proposals.

**Rules:**
- Do not duplicate existing content; connect to existing concepts when appropriate.
- Use clear file paths (e.g., `concepts/token-throughput.md`).
- Focus on actionable updates that will improve the skill’s completeness and utility.
