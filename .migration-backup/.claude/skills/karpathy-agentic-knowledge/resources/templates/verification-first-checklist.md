# Verification‑First Checklist

Before delegating a task to an agent, answer the following questions:

1. **Is there an objective metric or test to verify success?**  If no, keep the human in the loop.
2. **Are inputs and outputs clearly defined?**  Provide context and expected results.
3. **Are there constraints on what the agent can modify?**  Define scope and restrictions.
4. **Will the agent know when to stop?**  Include stop conditions or success criteria.
5. **Are there security or safety concerns?**  Limit access to sensitive systems.
6. **How will results be reviewed?**  Plan a code review or note summarisation step.
7. **Is there a fallback?**  Specify what to do if the task fails or cannot be verified.

Use this checklist to design tasks that are amenable to automation and avoid contributing to the slopacolypse.
