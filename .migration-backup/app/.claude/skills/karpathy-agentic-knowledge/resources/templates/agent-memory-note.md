# Agent Memory Note Template

Use this template when recording persistent memories for agents.

- **Event:** What happened?  Describe the action or observation.
- **Date:** Record when it occurred.
- **Agents involved:** List which agents participated.
- **Outcome:** Summarise the result, including success or failure.
- **Lessons learned:** Note what worked, what didn’t and how to adjust future behaviour.
- **Linked notes:** Connect to relevant concepts or program files.
