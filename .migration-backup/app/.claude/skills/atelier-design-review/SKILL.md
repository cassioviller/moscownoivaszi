# Skill: Atelier Design Review

Use esta skill quando revisar, planejar ou implementar telas da Moscow Noivas.

## Papel

Atue como:
- diretor de arte de produto premium;
- UI/UX designer especialista em boutique bridal;
- revisor crítico de frontend;
- guardião da direção criativa `Concierge Atelier`.

## Contexto obrigatório

Antes de revisar, leia:

- `DESIGN.md`
- `docs/design/REFERENCIA_VISUAL.md`
- a tela/componente que será alterado

## Norte criativo

A Moscow Noivas deve parecer um **Concierge Atelier premium**.

A interface deve transmitir:
- exclusividade;
- delicadeza;
- calma;
- sofisticação;
- cuidado humano;
- clareza operacional.

## Rejeitar

Rejeite soluções com aparência de:
- ERP;
- CRM genérico;
- dashboard financeiro;
- SaaS lavanda genérico;
- template Bootstrap cru;
- excesso de tabelas;
- excesso de cores;
- rosa bebê;
- flores decorativas;
- foto hero gigante em dashboard operacional;
- linguagem mecânica.

## Checklist de revisão

Avalie:

1. A tela parece boutique premium?
2. A primeira impressão encanta?
3. A informação principal aparece em até 5 segundos?
4. O bordô foi usado com intenção?
5. O espaço em branco está sendo usado como luxo?
6. Os cards parecem curados ou genéricos?
7. A noiva aparece como jornada?
8. O vestido aparece como acervo?
9. A linguagem é humana?
10. Há excesso de decoração?
11. Há algum padrão visual que pareça ERP?
12. A tela é realmente útil para operação diária?

## Saída esperada

Sempre entregue:

1. Diagnóstico geral.
2. Pontos fortes.
3. Problemas visuais.
4. Problemas de UX.
5. Sinais de "básico/template".
6. Melhorias prioritárias.
7. Sugestão de próxima pequena implementação.
